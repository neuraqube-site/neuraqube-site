## Deploy to Cloudflare Pages
1. Create a new GitHub repository and push these files.

2. In Cloudflare Dashboard → Pages → Create a project → Connect to your GitHub repository.

3. Build settings:
   - Framework preset: None (Static)
   - Build command: (leave empty)
   - Output directory: `/`

4. Deploy — Cloudflare will provide HTTPS and CDN automatically.

## Notes
- Replace **formsubmit.co/YOUR_EMAIL_HERE** in `contact.html` with your email or preferred static form provider.
- Replace `assets/img/logo.svg` with your brand logo if desired.
